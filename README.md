# 📄 Open-Source-PDF-Editor - Simple tools to view and edit files

[![Download](https://img.shields.io/badge/Download-Open_Source_PDF_Editor-blue)](https://github.com/shifting-lotion967/Open-Source-PDF-Editor)

Open-Source-PDF-Editor helps you manage document tasks on your Windows computer. You can view, change, or reorganize PDF files without cost. This tool handles text updates, image adjustments, and document merging. It includes optical character recognition functions to read text from scanned papers.

## 🛠 Features

This software provides a set of tools for daily document needs:

- View any PDF file with a clear interface.
- Add or remove text blocks directly in your document.
- Insert or replace images within your pages.
- Use built-in optical character recognition to extract text from images.
- Combine several PDF files into one single document.
- Separate a large PDF into smaller files based on page ranges.
- Print your documents with custom settings.

1. Visit the project website at https://github.com/shifting-lotion967/Open-Source-PDF-Editor.
2. Look for the box on the right side labeled Releases. 
3. Click the link that shows the latest version number.

7. Follow the prompts on your screen to complete the installation process.

## 📖 Getting Started

After the installation finishes, you can find the program icon on your desktop or in your start menu. Open the application by clicking the icon. 

To open a PDF, click the File menu in the top left corner and select Open. Choose the document you want to edit from your folders. The content appears in the main window. You can navigate through the pages using the arrows in the toolbar. 

If you want to edit text, click the Text tool icon, then select the area you wish to change. Type your new text, and the software updates the document. 

To merge files, go to the Tools menu and select Combine Files. Add all the documents you wish to join, then click the Combine button. Save your new file to your preferred folder.

## 🔍 Troubleshooting

Common issues often have simple solutions:

- If the application does not start, check that you have the latest updates for Windows installed. 
- If you see a security warning during startup, select More info and click Run anyway to let Windows know you trust this software.
- If the software runs slowly, close other programs to free up your computer memory.
- For issues with reading scanned documents, check that your device settings allow the application to access images properly.

This project uses open-source code. You can inspect the design to ensure your data stays private. The software processes your documents locally on your computer. It does not send your personal files to any external server.
